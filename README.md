# Roblox Fast Flags Manager - Linux

A GUI application to manage Roblox Fast Flags on Linux.

## 🚀 Features
- **Easy Configuration**: Add, edit, and remove Fast Flags with a user-friendly interface
- **Automatic Detection**: Finds your Roblox installation automatically
- **One-Click Apply**: Apply flags with a single button click
- **Configuration Saving**: Your flags are saved between sessions

## 📋 Prerequisites
- Python 3.6 or higher
- Tkinter (usually included with Python)
- Roblox installed on your Linux system
